# Road Guardian Web Service

A lightweight web service scaffold built with **Bun** and **Elysia.js** for high-throughput HTTP handling.

---

## Getting Started

### Prerequisites
- [Bun runtime](https://bun.sh/)

### Installation & Execution
```bash
cd web

# Install dependencies
bun install

# Start the development server
bun dev
```
The server will start on port `6969` (accessible at `http://localhost:6969`).
